### 💹 Investment Analysis Dashboard

**Business Problem**
Understand investor preferences, savings objectives, and expected returns to inform financial product/marketing decisions. Completed as part of the Cognifyz Technologies Business Analytics Internship.

**Tech Stack**
Python | Pandas | Matplotlib | Power BI | Power Query | DAX

**Analysis**
- Data overview, descriptive statistics, and gender/demographic breakdown (40 respondents)
- Frequency analysis of preferred investment avenues and information sources
- Correlation analysis between age, investment duration, and expected returns
- Interactive Power BI dashboard with KPI cards and drill-down visuals

**Key Insights**
Mutual Funds were the most preferred investment avenue (18/40 respondents); Financial Consultants were the most common information source (16/40); average investment duration was ~2.98 years across the sample.

**Tech Stack**
Power BI | Power Query | DAX | Excel

**Analysis**
